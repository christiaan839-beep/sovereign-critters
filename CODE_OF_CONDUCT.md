# Code of conduct

This project is small and the people in it are doing it for the love of it. A few plain rules keep it pleasant.

## What we ask

- Be kind and be specific. Say what is wrong with the work, not what is wrong with the person.
- Assume good faith, and say so when you are unsure what was meant.
- Welcome newcomers. A first issue or pull request gets patience, not a lecture.
- Keep to the subject: the mods, their code and their docs.
- Respect privacy. Do not post someone else's personal details, and do not paste a secret, a token or a private path into an issue.

## What is not welcome

Harassment, insults, discrimination, threats, sexual attention nobody asked for, and publishing private information. Also not welcome: pushing a person to act on a vulnerability in public. Report those by the private route in [`SECURITY.md`](SECURITY.md).

## Where it applies

In this repository's issues, pull requests, discussions and reviews, and wherever someone speaks for the project.

## What happens

The maintainers may edit or remove a comment, close a thread, or block a person from the repository when these rules are broken. We will say why, once, plainly.

## Reporting a problem

Tell a maintainer privately through the contact route on the [Sovereign Matrix profile](https://github.com/christiaan839-beep) on GitHub, or hide or flag the comment using GitHub's own tools. We will read it, keep the report private, and reply.
